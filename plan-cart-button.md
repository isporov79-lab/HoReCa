# План: Обновление кнопки «В корзину»

## Текущее состояние

- **Файл**: `css/catalog.css`
- **Класс**: `.excel-product-cart`
- **Текущий фон**: `#2a2f38` (близко к `#282D37`)
- **Текущий текст**: `#fff` (белый)
- **Hover**: `background: #00db99; color: #121212;` (зелёный акцент)

## Цель

- Сделать фон кнопки тёмно-серым/графитовым `#282D37`
- Текст — белый
- При нажатии (`:active`) фон темнеет до `#1f232b` + `transform: translateY(2px)`
- Убрать зелёный hover `#00db97`, оставить фирменный графит

## Изменения

### 1. Основной фон и текст

```css
.excel-product-cart {
  background: #282D37;
  color: #ffffff;
}
```

### 2. Hover

```css
.excel-product-cart:hover {
  background: #1f232b;  /* чуть темнее основного */
  color: #ffffff;        /* белый текст сохраняем */
}
```

### 3. Active (эффект нажатия)

```css
.excel-product-cart:active {
  background: #1f232b;
  transform: translateY(2px);
}
```

### 4. Состояние «в корзине» (`.in-cart`)

```css
.excel-product-cart.in-cart {
  background: #1f232b;
  color: #ffffff;
}
```

## Проверка

- Открыть каталог
- Убедиться, что кнопка «В корзину» имеет фон `#282D37` и белый текст
- Навести — фон не зелёный, остаётся в графитовой гамме
- Нажать и удерживать — кнопка «утопает» (`translateY(2px)`) и становится чуть темнее
- После отпускания возвращается к `#282D37`

## Файлы для правки

- `css/catalog.css` — класс `.excel-product-cart` и его псевдоклассы `:hover`, `:active`, модификатор `.in-cart`
